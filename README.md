# Nostos

Juego en Unity 6 (URP 17.3). El proyecto vive en la Steam Deck de Toni; este repositorio lleva los
archivos que se escriben desde Claude (código, modelos generados, pipeline de Blender y los cambios
a paquetes de la tienda), para copiarlos al proyecto con:

    git fetch origin main && git checkout origin/main -- .

Los paquetes de la tienda (Assets/StarSparrow, Polytope, etc.) no están aquí salvo los archivos que
se han modificado o convertido a URP.
